# 🚗 GaragePoint – Garage Management System

GaragePoint is a modern full-stack garage service management application built using the MERN-style stack. It helps customers manage vehicle services, bookings, invoices, and dashboard analytics through a professional and responsive interface.

---

## 🌐 Live Demo

### Frontend

https://garagepoint-fullstack.vercel.app

### Backend API

https://garagepoint-backend.onrender.com

---

## ✨ Features

* 🔐 User Authentication
* 🚘 Vehicle Management
* 📅 Service Booking System
* 📊 Dashboard Analytics
* 🧾 Invoice/Billing System
* 👨‍🔧 Admin Dashboard
* 📱 Fully Responsive UI
* ⚡ Fast React Frontend
* 🌍 Deployed Frontend & Backend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/malleshchittegonda/garagepoint-fullstack.git
```

---

## 🚀 Frontend Setup

```bash
cd client
npm install
npm start
```

Frontend runs on:

```bash
http://localhost:3000
```

---

## 🚀 Backend Setup

```bash
cd server
npm install
npm start
```

Backend runs on:

```bash
http://localhost:5000
```
